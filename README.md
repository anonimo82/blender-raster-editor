# Blender Raster Editor

Blender Raster Editor is a Blender add-on that brings a familiar raster-layer workflow into the 3D Viewport. It lets artists build, paint, mask, reorder, and blend image layers on a canvas while the add-on manages the underlying shader-node composition automatically.

The add-on is intended for hand-painted artwork, texture painting, simple compositing, rotoscoping, and other workflows where image layers need to remain editable inside Blender.

## Main Features

- Create a ready-to-paint canvas with a node-based material.
- Add, remove, duplicate, rename, show, hide, and reorder raster layers.
- Assign generated images, external images, movies, or image sequences to layers.
- Paint directly on a layer or on its mask through Blender's Texture Paint tools.
- Use 19 blend modes and per-layer opacity.
- Add, enable, disable, paint, and remove grayscale masks.
- Resize every compatible layer canvas without stretching the existing pixels.
- Merge visible layers into a new baked image while preserving the originals as hidden layers.
- Create or reuse an orthographic camera framed to the canvas.
- Keep the material shader graph synchronized automatically.

## Requirements

- Blender 4.0 or newer.
- Cycles is required temporarily when using **Merge Visible**.
- NumPy, included with Blender.

## Installation

1. Download the repository as a ZIP file.
2. In Blender, open **Edit > Preferences > Add-ons**.
3. Choose **Install from Disk**, select the ZIP, and enable **Blender Raster Editor**.
4. Open the 3D Viewport sidebar with `N` and select the **Paint Layers** tab.

## Basic Use

1. Click **Create Canvas**.
2. Add or select a layer and assign an image with **New** or **Open**.
3. Click the paint-target button beside the layer.
4. Switch Blender to **Texture Paint** mode and paint.
5. Add more layers, choose blend modes, adjust opacity, or create masks.
6. Save or pack every edited image before closing Blender.

A complete example is available in [Tutorial.md](Tutorial.md). Detailed reference documentation is maintained in the [GitHub Wiki](https://github.com/anonimo82/blender-raster-editor/wiki).

## Important Notes

Blender does not automatically save modified image pixels inside the `.blend` file unless the image is packed. Save images from the Image Editor or use **Image > Pack** regularly.

The shader nodes generated by the add-on are marked as managed. Editing or deleting them manually can desynchronize the layer stack; use **Apply Opacity** to force a rebuild when needed.
